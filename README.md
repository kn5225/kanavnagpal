# Portfolio Website

My personal portfolio website showcasing my engineering projects, technical skills, and research work. Built with a focus on high-performance, responsive design, and smooth transitions.

## 🚀 Live Site

Check out the live site here: [Portfolio](https://kn5225.github.io/kanavnagpal/)

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (modern Flexbox/Grid, custom variables), JavaScript (ES6)
- **Animations:** Intersection Observer API (scroll reveal transitions)
- **Media Optimization:** Custom FFmpeg pipeline for fast-loading, hardware-accelerated video loops

## 📂 Project Structure

```
├── index.html          # Main entrypoint
├── style.css           # Core styling & responsive layouts
├── main.js             # Scroll animations and interactive behaviors
├── favicon.ico         # Custom icon for the site
└── demos/              # Optimized MP4 demo clips
```
